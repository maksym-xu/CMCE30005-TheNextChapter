# Final report evidence

The [2 October paired model comparison](paired-analysis-2026-10-02/README.md) evaluates logistic regression and the simple segment-rate baseline on the same 50 host splits, using the same test listings and shortlist quota in each split. It includes training-only missing-value handling, precision, AUC, Brier and their paired differences, with reproducible code and aggregate verification records.

The average shortlist target rate is 43.42% for logistic regression and 31.96% for the baseline, a paired gain of 11.46 percentage points. Logistic screening is better in 48 of the 50 splits. These are exploratory retrospective sensitivity results, not independent external tests or forecasts of future profit.

The [English speaking script](../final-presentation/english-script-2026-10-02/README.md) distinguishes this new comparison from the original five-fold result shown in the presentation. It contains the ten-slide spoken script, four-presenter timing, twelve prepared answers and an evidence summary.
